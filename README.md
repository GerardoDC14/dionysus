Dionysus is a personal desktop “rice” built around a Nord-inspired, neon-accent visual language. The repository collects the configuration, scripts and assets used across the shell, terminal, launcher, status bar and desktop widgets.

## Components

| Directory | Purpose |
|---|---|
| `alacritty/` | Terminal configuration and color palette |
| `cava/` | Audio visualizer and raw-output configuration |
| `eww/` | Desktop widgets, HUD and helper scripts |
| `firefox/` | Browser theme customizations |
| `hypr/` | Hyprland compositor and keybinding configuration |
| `neofetch/` | Animated system-information presentation |
| `rofi/` | Application launcher and power menu |
| `waybar/` | Status bar configuration and modules |
| `zsh/` | Shell configuration |
| `assets/` | Screenshots, GIFs and visual resources |

## Visual direction

- Nord-inspired base palette;
- neon and radioactive accent elements;
- animated system information;
- CAVA integration with Eww and terminal output;
- cohesive launcher, terminal, bar and widget styling.

## Notes

These files reflect a specific Arch Linux installation and hardware setup. Device names, audio sources, monitor definitions and paths may require adjustment before reuse on another system.
